# 🧮 CALCULADORA DE IDADE
Este projeto é uma Calculadora de Idade desenvolvida em Python, utilizando as bibliotecas Tkinter (para interface gráfica) e Tkcalendar (para seleção de datas).
O programa permite calcular a idade de uma pessoa em anos, meses e dias, a partir da data de nascimento e uma data de referência escolhida pelo usuário.

### 🚀 Funcionalidades

✔️ Interface gráfica intuitiva
✔️ Seleção de datas pelo calendário interativo
✔️ Cálculo preciso da idade em anos, meses e dias
✔️ Exibição clara dos resultados na tela

### 🛠️ Tecnologias utilizadas

- Python 3.x

- Tkinter → para construção da interface gráfica

- Tkcalendar → para trabalhar com calendário

- Dateutil (relativedelta) → para cálculo detalhado da diferença entre as datas
